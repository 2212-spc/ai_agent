# 🤖 AI Agent Studio - Intelligent Dialogue Assistant

A powerful AI Agent platform integrating RAG (Retrieval-Augmented Generation), MCP tool calling, web search, and long-term memory systems, providing a professional-grade user interface similar to ChatGPT and Coze.

**🎉 New Vue 3 Frontend Now Available!** Offering a better development experience and user interaction.

**🐳 One-Click Docker Deployment**: No environment configuration needed, one-click startup, full functionality, and no VPN required!

- 🧠 **Intelligent Long-term Memory** - Automatic extraction, deduplication, and vectorized retrieval, allowing the AI to truly remember the user.
- 🤖🤖🤖 **Multi-Agent System** (Latest) - Collaboration between multiple expert agents, automatic task decomposition, intelligent result aggregation, and Prompt template management.
- 📚 **Session Management** - Complete dialogue history retrieval, conversation continuation, and memory sharing control.
- 🔍 **Vectorized Retrieval** - ChromaDB support, semantic similarity search with confidence assessment.
- 🤖 **LangGraph Agent** - Multi-step planning, intelligent routing, and tool calling.
- 📄 **RAG Knowledge Base** - Document upload, vector retrieval, and intelligent chunking.
- 🌐 **Web Capabilities** - Web search, content extraction, weather queries, and intelligent tool calling.
- 🎯 **Prompt Template Management** (Latest) - Database storage, dynamic loading, and placeholder replacement for flexible agent behavior customization.

- `{full_context}` - Full context

```bash
# 1. Clone the project
git clone <your-repo-url>
cd ai_agent

# 2. Configure environment variables
cp .env.example .env
# Edit the .env file and fill in your DEEPSEEK_API_KEY

# 3. One-click start (Windows)
start.bat

# Or one-click start (Linux/Mac)
chmod +x start.sh
./start.sh

# Or use Docker Compose directly
docker-compose up -d
```

#### Access the Application

- **Frontend Interface**: http://localhost
- **Backend API Docs**: http://localhost:8000/docs

#### 📝 Notes

- **Data Persistence**: All data is saved in the `backend/data/` directory; deleting the container will not result in data loss.

For detailed documentation, see: [Docker Deployment Guide](DOCKER_DEPLOYMENT.md)

### Using the Multi-Agent System (Latest Feature)

The multi-agent system is ideal for complex research tasks, providing more comprehensive and accurate answers through the collaboration of multiple expert agents.

**Use Cases:**
- 📚 **Research Assistant**: Complex questions requiring retrieval, analysis, and summarization.
- 🔍 **Deep Investigation**: Thematic research requiring multi-perspective analysis.
- 📊 **Data Analysis**: Data tasks requiring extraction, analysis, and visualization.

**Usage Method:**
```
# Call Multi-Agent API endpoint
POST /chat/multi-agent/stream
{
  "messages": [{"role": "user", "content": "Please research the latest progress in diffusion models"}],
  "use_knowledge_base": true,
  "use_tools": true,
  "execution_mode": "sequential"  // or "parallel"
}
```

**Workflow:**
1. **Coordinator Planning** - Analyzes the task, decomposes it into sub-tasks, and selects appropriate agents.
2. **Retrieval Specialist** - Retrieves from knowledge base (with confidence assessment; low confidence is skipped), calls intelligent tools (LLM determines needs), performs web search, and finds documents.
3. **Analysis Specialist** - Deeply analyzes retrieved content and extracts key information (supports custom Prompt templates).
4. **Summarization Specialist** - Intelligently selects information sources, integrates all data, and generates a structured report (supports custom Prompt templates).
5. **Verification Specialist** - Quality checks and fact-checking (optional, supports custom Prompt templates).

**New Features:**
- 🎯 **Intelligent Tool Calling** - LLM automatically analyzes the user's question to determine which tools to call (weather, search, etc.).
- 📊 **Confidence Assessment** - Knowledge base retrieval results include confidence scores; low-relevance content is automatically skipped.
- 🔄 **Intelligent Source Selection** - The summarization specialist automatically selects the most relevant sources based on quality.
- 📝 **Prompt Template Management** - Support for custom Prompt templates for each agent, with dynamic loading without restarting.

**Advantages:**
- 🎯 **Precise Task Decomposition** - AI automatically breaks down complex tasks.
- ⚡ **Higher Efficiency** - Specialized agents process in parallel; intelligent tool calling reduces invalid operations.
- 🔍 **More Comprehensive Results** - Multi-perspective collaboration for more complete information.
- ✅ **More Reliable Quality** - Multi-agent verification ensures more accurate answers.
- 🎨 **Highly Customizable** - Prompt template management system allows flexible adjustment of agent behavior.

2. Fill in the following:

### Using the Long-term Memory System

**Automatic Memory Extraction:**
The system automatically extracts important information after each conversation, for example:
- User mentions name or profession → stored as `fact` type.
- User expresses preference (like/dislike) → stored as `preference` type.
- User mentions events or plans → stored as `event` type.

**Automatic Memory Deduplication:**
The system intelligently detects and merges similar memories. For example:
```
1st Conversation: "My name is Zhang San"
2nd Conversation: "I am called Zhang San"
→ Automatically merged to avoid redundancy.
```

**Memory Retrieval:**
The AI automatically retrieves relevant memories when answering:
```
User: "Do you remember my name?"
AI: (Retrieving memory) → "Of course, your name is Zhang San."
```

### Using Session Management

**Viewing Conversation History:**
1. Click the **📚 Conversation History** button in the top right of the chat interface.
2. View the list of all historical sessions.
3. Use the search box to find specific content within conversations.

**Continuing a Conversation:**
1. Click the desired conversation in the history list.
2. The system automatically loads historical messages.
3. You can seamlessly continue from where you left off.

**Deleting Sessions:**
1. Click the **🗑️** button on the history page.
2. Confirm deletion to permanently remove all messages in that session.

**Configuring Memory Sharing:**
1. Click the **⚙️ Session Settings** button in the top right of the chat interface.
2. Toggle the **Share Memory Across Sessions** switch:
   - **ON**: AI can access long-term memory stored across all sessions.
   - **OFF**: AI only accesses memory within the current session (Session Isolation).
3. Settings are saved automatically.

### Using the Prompt Template Management System

**Viewing and Managing Templates:**
1. Visit the Prompt Management page (usually in settings or management interface).
2. View the list of templates for all agents.
3. Each agent can have multiple templates, but only one is active.

**Creating Custom Templates:**
1. Select the agent to create a template for (e.g., `analysis_specialist`).
2. Enter the template name, description, and content.
3. Use placeholders in the content, such as `{user_query}` and `{task_description}`.
4. After saving, the template is automatically activated (if it's the first template for that agent).

**Activating Templates:**
1. Find the template you want to activate in the list.
2. Click the "Activate" button.
3. The system automatically deactivates other templates for that agent.
4. Changes take effect immediately without restarting the service.

**Editing Templates:**
1. Click the "Edit" button of a template.
2. Modify the content, name, or description.
3. Changes take effect immediately upon saving.

**Deleting Templates:**
- Only non-default templates can be deleted.
- Default templates (`is_default=true`) are protected and cannot be deleted.
- If no active template remains after deletion, the system uses the hard-coded default prompt.

**Placeholder Usage Example:**
```
You are a senior analysis expert. Please analyze the following:

User Query: {user_query}
Task Requirements: {task_description}
Content to Analyze: {analysis_context}

Please provide a detailed analysis report.
```

**Precautions:**
- Template content supports Markdown format.
- Placeholders use single curly brace `{variable_name}` format.
- If a placeholder is undefined, the system logs a warning but does not interrupt execution.
- The system automatically handles double curly brace escaping (`{{` → `{`).

## 🐛 FAQ

### Q: Why is the first installation so slow?
A: This is normal. The system needs to download embedding models (approx. 500MB) and dependency packages. Please be patient.

### Q: Why aren't mathematical formulas showing?
A: Ensure your network is connected; the KaTeX library needs to be loaded from a CDN. You can press F12 to check for console errors.

### Q: Why is the search function unavailable?
A: Check your network connection and ensure you can access DuckDuckGo. Users in China can usually access it directly.

### Q: Why did the Docker build fail?
A: 
1. Ensure Docker Desktop is running.
2. Check your network; the Dockerfile is configured with domestic mirror sources.
3. If it still fails, try: `docker-compose build --no-cache`.
4. Check detailed logs: `docker-compose logs`.

### Q: Does Docker deployment require a VPN?
A: **No!** The Dockerfile uses domestic mirror sources (Alibaba Cloud), so users in China can use it directly without a VPN.

### Q: Why did the DeepSeek API call fail?
A: Check the following:
1. Is the API Key set correctly?
2. Is there remaining credit/quota?
3. Is the network connection stable?

### Q: Why did the document upload fail?
A: Ensure that:
1. The file format is PDF.
2. The file size is reasonable (< 100MB).
3. The file is not encrypted.

### Q: Why wasn't my memory remembered?
A: Check:
1. Does the conversation contain explicit factual or preference information?
2. Memory extraction requires a certain threshold of importance; trivial information may not be extracted.
3. Check session settings to ensure "Share Memory Across Sessions" is enabled.

### Q: How do I isolate memory between sessions?
A: Turn off the "Share Memory Across Sessions" switch in session settings. The AI will then only access memory from the current session.

### Q: How do I delete conversation history?
A: Visit the Conversation History page and click the 🗑️ button next to the session you wish to delete.

### Q: Error during registration because the password is too long?
A: The system has been optimized to support passwords of any length. If a password exceeds 72 bytes, the system automatically applies secure processing (SHA-256 hash + Base64 encoding) to ensure safe storage.

### Q: Why does the login page keep refreshing?
A: This is usually caused by a loop due to token verification failure. Solution:
1. Clear browser cache and `localStorage`.
2. Log in again.
3. If "Remember Me" was checked, ensure the token is still valid.

### Q: What if I forget my password?
A: The current version is in demo mode and does not support password reset. To reset:
1. Delete the user record from the database.
2. Register a new account.

### Q: Can I log into multiple accounts simultaneously?
A: The current version stores authentication info in `localStorage`, so only one account can be logged in per browser. Please log out to switch accounts.
